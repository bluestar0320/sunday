# 🐾 같이걸을개 — 산책으로 시작하는 만남

어색한 카페 소개팅 대신, **강아지와 함께 걷는 편안한 첫 만남**을 연결해 주는 소개팅 앱 프로토타입입니다.
빌드 과정 없는 모바일 웹앱(HTML/CSS/JS)이고, 데이터는 브라우저 `localStorage`에 저장됩니다.

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| 온보딩 | 보호자 정보 → 강아지 정보(크기·에너지·사회성·성격·**건강**) → 강아지 사진 업로드(최대 5장, 1장 이상 필수) |
| 탐색 | 사진 중심 카드, **산책 궁합 점수**순 추천, 받은 매너 평가·건강 정보·인증 배지·"만나기 전에 알아두세요", 거리·크기·성별·**접종 완료·인증 회원** 필터 |
| 대화 | **나를 좋아한 사람** 목록(바로 매칭), 새 매칭·대화 목록 |
| 채팅 | 메시지·**사진** 보내기, **읽음 표시(1)**, 산책 제안 카드(수락·다른 시간·거절), 첫 산책 전 **연락처 공유 주의**, 받은 메시지의 연락처·링크·**금전 요청 경고**, 상세 신고 |
| 산책 › 내 일정 | 답 대기/확정/완료, 일정 변경·취소, 날씨 예보, 알림 예정 시간, **안심 산책 시작**, 매너 평가(노쇼 신고) |
| 산책 › 동네 모임 | 3~6명 그룹 산책 둘러보기·참여·나가기·**모임 만들기**(안심 코스만) |
| 산책 › 산책 기록 | 함께 걸은 코스·거리·시간 기록, 사진·메모, 누적 통계, **또 같이 걸어요** |
| 안심 산책 | 실시간 위치 공유(데모 링크), 경로 위 현재 위치, 중간 체크인, **예정 시간 초과 시 지인 자동 알림**, 긴급 SOS(112·문자·경보음·가까운 지구대) |
| 코스 지도 | 산책 경로, 주의 구간, CCTV·편의점·지구대, 중간 지점. 시간대별 주의 구간, 드래그·확대/축소 |
| 알림 센터 | 산책 전날·1시간 전 알림, 매칭·좋아요, 모임 참여, 안심 산책 기록, 매너 평가 (선택: 기기 알림) |
| MY | 사진, 건강 정보, **본인·동물등록 인증**, **받은 매너 평가**, 안심 연락처·자동 알림 설정, 안심 코스 모드 |

### 이번에 추가한 기능 (1~8)

1. **산책 당일 안심 기능** (`js/safety.js`) — 안심 연락처(최대 3명), 산책 시작 시 위치 공유할 사람 선택, 20분마다 체크인, 예정 종료 시간 + 15분이 지나면 지인에게 자동 알림, 15분 연장, 긴급 SOS, 다른 화면의 "안심 산책 중" 띠. 데모용 "10분 앞으로 감기"가 있어요.
2. **강아지 건강·성향 정보와 인증 배지** — 예방접종·중성화·입질 이력·알러지. 입질 이력(−20점)과 미접종(−10점)은 궁합 점수에 반영되고 주의사항으로 보여요. 본인 인증(데모 인증번호 123456)과 동물등록번호(15자리) 인증.
3. **일정 조율** — 상대가 수락하거나, 비 예보·안 맞는 시간대·주의 코스 때문에 다른 시간을 제안해요(데모 규칙). 전날·1시간 전 알림(3시간 안 남았으면 전날 알림은 생략). 날씨는 날짜별로 고정된 데모 예보예요.
4. **받은 좋아요** — 나를 좋아한 사람을 먼저 보고 바로 매칭. 일부 샘플(민준·하은)은 내가 좋아요를 보내면 잠시 뒤 좋아요로 답해요.
5. **동네 산책 모임** (`js/groups.js`) — 정원·강아지 크기 제한, 지난 모임 제외, 모임은 안심/보통 코스에서만 열 수 있어요. 내가 연 모임에는 데모 이웃이 10초 간격으로 2명까지 참여해요.
6. **산책 기록과 또 걸어요** (`js/records.js`) — 산책이 끝나면 자동 기록, 사진(최대 4장)·메모, 같은 코스로 다시 제안. 별점 4점 이상 + "또 만나고 싶어요"면 두 번째 산책을 권해요.
7. **매너 평가 표시와 불이익** — 평균 별점·상위 태그·"매너 우수"(4.5점 이상, 5개 이상, 노쇼 없음). 노쇼 신고가 2회 쌓이면 추천·받은 좋아요·모임에서 제외돼요. 3시간 이내 취소는 늦은 취소로 기록돼요.
8. **채팅 보완** — 사진 보내기, 읽음 표시, 첫 산책 전 연락처 공유 확인, 받은 메시지의 연락처·링크·금전 요청 경고와 바로 신고, 사유·대화 첨부·차단을 고르는 상세 신고.

> 데모라서 서버가 없어요. 문자·위치 공유 링크·본인 인증·상대방의 답장/수락/평가는 실제로 보내지지 않고 앱 안에서 흉내 냅니다.

### 산책 궁합 점수 (0~100)

`js/logic.js`의 `compatibility()`에서 계산합니다.

- 거리 (최대 30점) — 가까울수록 산책 약속이 쉬움
- 강아지 크기 차이 (최대 20점)
- 산책 에너지/페이스 (최대 20점)
- 겹치는 산책 시간대 (최대 20점)
- 공통 관심사 (최대 10점)
- 다른 강아지와 천천히 친해지는 아이가 있으면 −15점

### 안심 코스 체크 (으슥한 곳 피하기)

`js/logic.js`의 `courseSafety(course, slot)`가 **선택한 시간대 기준**으로 코스마다 5가지를 확인합니다.

| 항목 | 기준 |
| --- | --- |
| 유동인구 | 그 시간대에 사람이 다니는지 (드묾/보통/많음) |
| 조명 | 저녁·밤에 가로등이 밝은지 (낮에는 통과) |
| CCTV | 방범 CCTV 설치 구간인지 |
| 트인 시야 | 숲길·골목처럼 가려진 구간이 없는지 |
| 도움 요청 | 편의점·지구대까지 300m 이내인지 |

점수에 따라 **안심 / 보통 / 주의**로 나뉘고, 어두운 시간에 인적까지 드문 코스는 점수와 관계없이 **주의**가 됩니다.
안심 모드(기본 켜짐)에서는 주의 코스를 추천에서 빼고 "으슥한 코스 N곳을 숨겼어요"라고 알려줍니다.
같은 공원도 낮엔 안심, 밤엔 주의가 될 수 있습니다. 주의 코스로 제안하려고 하면 한 번 더 확인합니다.

> 코스 안전 데이터는 데모용 샘플입니다. 실서비스에서는 공공데이터(가로등·CCTV 위치, 안심지킴이집, 유동인구)와 이용자 제보로 채워야 합니다.

### 코스 지도

코스 제안 시트에서 코스를 고르면 미니 지도가 보이고, **지도 크게 보기**, 채팅의 산책 카드, 산책 일정의 **지도** 버튼으로 전체 화면 지도가 열립니다.

- 외부 지도 SDK·API 키 없이 `js/map.js`가 SVG로 그리는 간략 지도입니다. 한강·공원·주요 도로·역은 `js/data.js`의 `MAP`에 있는 단순화한 형태라 실제 지도와 정확히 일치하지 않습니다.
- 코스 경로(`path`)에서 거리와 소요 시간(반려견 걸음 약 3.5km/h)을 계산합니다.
- 주의 구간은 경로 위 점에 표시하고(`h`), 저녁·밤에만 주의인 구간(`night`)과 항상 주의인 구간(`always`)을 나눕니다. 낮에는 밤 전용 주의 구간이 회색으로 바뀝니다.
- 상대방의 정확한 위치는 표시하지 않고 **중간 지점**만 보여줍니다.
- 실서비스에서는 카카오맵·네이버 지도 SDK로 바꾸면 됩니다. `mountMap(el, { course, slot, mid })` 하나만 교체하면 되도록 분리해 두었습니다.

### 디자인 — "아침 산책길"

- 크림빛 바탕에 세이지 그린(주요 버튼·내 말풍선)과 살구빛(좋아요·알림) 포인트. 밤에는 깊은 숲빛 다크 모드.
- 제목·이름은 둥글고 부드러운 **고운돋움**(Gowun Dodum, OFL), 본문은 Pretendard.
  고운돋움은 `fonts/gowun-dodum/`에 포함되어 있어 인터넷 없이도 표시됩니다.
- 알약 모양 버튼, 떠 있는 하단 탭, 둥근 카드와 부드러운 그림자.
- 배경에 햇살과 천천히 흩날리는 잎사귀, 카드가 바람에 살랑 들어오는 애니메이션, 좋아요를 누르면 하트가 떠오르는 효과.
  기기에서 '동작 줄이기'를 켜면 애니메이션은 꺼집니다.

### 사진

업로드한 사진은 브라우저에서 긴 변 900px JPEG로 줄여 저장합니다.

샘플 보호자의 강아지 캐릭터는 Higgsfield(Z Image 모델)로 생성한 수채화풍 이미지입니다(`js/data.js`의 `CHARACTERS`).
생성 원본(1536×2048 PNG) 대신 가벼운 미리보기 WebP를 Higgsfield CDN에서 바로 불러오고,
불러오지 못하면(오프라인 등) 그 아래 깔린 SVG 일러스트가 대신 보입니다.

## 실행 방법

```bash
cd walk-date
npm start            # node server/server.js → http://localhost:8080
```

- 외부 패키지 설치 없이 Node 18 이상이면 실행돼요. 서버가 앱 파일도 함께 제공해요.
- 시연할 때는 주소 뒤에 `?demo=1` 을 붙이세요 (예: `http://localhost:8080/?demo=1`). '10분 앞으로 감기', '완료 처리' 같은 데모 버튼이 보여요. MY > **데모 기능 보기**로도 켜고 끌 수 있어요. 기본은 꺼져 있어요.
- 서버 없이 화면만 보려면 `npm run static` (이때는 모든 서비스가 데모로 동작).

## 실제 서비스 연결하기

키를 넣지 않은 기능은 자동으로 데모로 동작해요. MY > **연결된 서비스**에서 상태를 볼 수 있어요.

| 서비스 | 쓰이는 곳 | 넣는 곳 | 준비할 것 |
| --- | --- | --- | --- |
| 기상청 단기예보 | 산책 제안·일정·모임의 날씨, 비 예보 경고 | `.env` 의 `KMA_SERVICE_KEY` | [공공데이터포털](https://www.data.go.kr)에서 '기상청_단기예보 조회서비스' 활용 신청 → 일반 인증키(Encoding) |
| 문자 발송 (솔라피) | 안심 산책 시작·체크인·예정 시간 초과·종료·긴급 문자 | `.env` 의 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER` | [솔라피](https://solapi.com) 가입, API 키 발급, 발신번호 등록(본인 인증 필요). 건당 요금 발생 |
| 휴대폰 인증 | MY > 본인 인증 (문자로 6자리 인증번호, 3분 유효, 5번까지 시도) | 문자 발송 키와 같음 | 위와 같음 |
| 카카오 지도 | 코스 지도 전체 화면 | `js/config.js` 의 `kakaoMapKey` | [카카오 개발자](https://developers.kakao.com) 앱 만들기 → JavaScript 키 → 플랫폼 > Web 에 서비스 주소 등록 |

```bash
cp .env.example .env   # 값 채우기 (.env 는 깃에 올라가지 않아요)
npm start              # 시작할 때 어떤 서비스가 연결됐는지 출력돼요
```

- 날씨·문자 키는 비밀 키라 브라우저가 아니라 서버(`server/server.js`)에만 둬요. 서버는 `.env`, `server/` 폴더, 숨김 파일을 밖으로 내보내지 않아요.
- 기상청 단기예보는 약 3일치만 있어서, 그보다 먼 날짜는 데모 예보로 보여요.
- 문자 발송은 IP당 1분에 10번, 받는 사람 3명, 300자로 제한했어요. 실제 출시 땐 로그인 사용자 기준 제한과 회원 서버가 필요해요.
- 실시간 위치 공유 화면(지인이 지도에서 계속 보는 페이지)은 아직 없어요. 지금은 시작·체크인·초과·종료 때 문자와 카카오맵 위치 링크를 보내요.
- 통신사 본인확인(PASS)은 별도 계약이 필요해서, 지금은 문자 인증번호 방식이에요.

## 안전 · 매너 규칙

`js/logic.js` 의 `RULES` 한 곳에서 바꾸면 동작과 안내 문구가 함께 바뀌어요.

| 규칙 | 기본값 |
| --- | --- |
| 예정 종료 후 지인 자동 알림 (MY에서 10·15·30분 변경 가능) | 15분 |
| 안심 산책 체크인 간격 (MY에서 15·20·30분 변경 가능) | 20분 |
| 연장 버튼 한 번에 늘어나는 시간 | 15분 |
| 추천·제안이 제한되는 노쇼 횟수 | 2회 |
| 늦은 취소로 기록되는 기준 | 약속 3시간 전 이내 |
| 전날 알림을 건너뛰는 기준 | 약속까지 3시간 미만 |
| 첫 산책 전 연락처 공유 확인 | 켜짐 |

## 데모 참고

- 샘플 보호자가 마포구(망원·연남·상암) 일대에 있습니다. `likes`에 `me`가 있는 사람에게 좋아요를 누르면 바로 매칭돼요. (노쇼가 쌓인 샘플 1명은 추천에서 빠져 있어요)
- 산책 제안은 2.5초 뒤 상대가 수락하거나, 비 예보·시간대·코스 안전 때문에 다른 시간을 제안해요.
- 데모 기능을 켜면(`?demo=1`) 산책 일정의 **완료 처리**, 안심 산책의 **10분 앞으로 감기**로 시간이 지난 뒤의 흐름을 바로 볼 수 있어요.
- 내 프로필 > **데모 데이터 초기화**로 처음부터 다시 시작할 수 있습니다.

## 실서비스로 확장할 때

- 백엔드(회원/매칭/채팅 API, 실시간 채팅은 WebSocket), 실제 위치(Geolocation) 및 위치 정보 동의
- 휴대폰 본인 인증(PASS 등)·성인 인증, 동물등록번호는 국가동물보호정보시스템 조회
- 안심 산책 위치 공유·자동 알림 문자는 서버와 문자 발송 API(SMS) 필요, 실제 GPS 위치 사용
- 날씨는 기상청 단기예보 API로 교체
- 신고 처리 운영 도구, 매너 평가 기반 노출 제한
- 지도 SDK(카카오/네이버 지도)로 교체하고, 코스 경로는 실제 산책로 데이터로 채우기
- 사진은 서버 스토리지에 저장하고 업로드 시 검수(사람 얼굴·연락처 노출 차단)
