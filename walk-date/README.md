# 🐾 같이걸을개 — 산책으로 시작하는 만남

어색한 카페 소개팅 대신, **강아지와 함께 걷는 편안한 첫 만남**을 연결해 주는 소개팅 앱 프로토타입입니다.
빌드 과정 없는 모바일 웹앱(HTML/CSS/JS)이고, 데이터는 브라우저 `localStorage`에 저장됩니다.

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| 온보딩 | 보호자 정보(이름·출생연도·성별·만나고 싶은 사람·산책 시간·관심사) + 강아지 정보(크기·에너지·사회성·성격) 입력 |
| 탐색 | **산책 궁합 점수**순으로 근처 보호자 추천, 좋아요/다음에, 거리·강아지 크기·성별 필터 |
| 매칭 | 서로 좋아요 시 매칭 성사 팝업, 새 매칭/대화 목록, 안 읽은 메시지 뱃지 |
| 채팅 | 메시지 전송(데모 자동 답장), **산책 제안**(두 사람 중간 지점 근처 코스 추천 + 날짜·시간대 선택) |
| 산책 일정 | 수락 대기/예정/완료 상태, 취소, 산책 후 **매너 평가**(별점·태그·재만남 의사) |
| 안전 | 약속 정보 지인 공유(클립보드), 신고, 차단(대화·일정 숨김), 공공장소 만남 안내 |

### 산책 궁합 점수 (0~100)

`js/logic.js`의 `compatibility()`에서 계산합니다.

- 거리 (최대 30점) — 가까울수록 산책 약속이 쉬움
- 강아지 크기 차이 (최대 20점)
- 산책 에너지/페이스 (최대 20점)
- 겹치는 산책 시간대 (최대 20점)
- 공통 관심사 (최대 10점)
- 다른 강아지와 천천히 친해지는 아이가 있으면 −15점

## 실행 방법

ES 모듈을 사용하므로 `file://`로 열지 말고, 로컬 서버로 띄워주세요.

```bash
cd walk-date
npm start            # http://localhost:8080
# 또는
python3 -m http.server 8080
```

## 테스트

```bash
cd walk-date
npm test             # node:test로 매칭/거리/일정 로직 검증
```

## 데모 참고

- 샘플 보호자 8명이 마포구(망원·연남·상암) 일대에 있습니다. `likes`에 `me`가 있는 사람에게 좋아요를 누르면 바로 매칭돼요.
- 산책 제안은 2.5초 뒤 상대가 자동 수락합니다.
- 산책 일정의 **완료 처리** 버튼으로 시간이 지난 것처럼 만들어 매너 평가 흐름을 확인할 수 있어요.
- 내 프로필 > **데모 데이터 초기화**로 처음부터 다시 시작할 수 있습니다.

## 파일 구조

```
walk-date/
├── index.html        # 앱 셸 (상단 바, 하단 탭, 모달)
├── styles.css        # 모바일 우선 스타일, 다크 모드 지원
├── js/
│   ├── app.js        # 화면 렌더링·상태 관리·이벤트
│   ├── logic.js      # 궁합 점수, 거리, 추천, 장소 제안 등 순수 로직
│   └── data.js       # 샘플 보호자/강아지, 산책 장소 데이터
└── test/logic.test.js
```

## 실서비스로 확장할 때

- 백엔드(회원/매칭/채팅 API, 실시간 채팅은 WebSocket), 실제 위치(Geolocation) 및 위치 정보 동의
- 휴대폰 본인 인증·성인 인증, 사진 업로드 및 검수
- 신고 처리 운영 도구, 매너 평가 기반 노출 제한
- 지도 SDK(카카오/네이버 지도)로 산책 코스 표시
